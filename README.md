# Robot Workshop | کارگاه ربات‌ها

نمونه اولیه یک بازی مدیریتی سه‌بعدی برای اندروید با موتور **Godot 4**.

## امکانات فعلی
- محیط سه‌بعدی کارگاه با رابط فارسی و دکمه‌های لمسی
- نمایش ربات خیالی قابل تغییر رنگ
- دریافت سفارش‌های خیالی از بات‌ها و گرفتن سکه
- ارتقای سطح کارگاه با سکه‌های بازی
- انتخاب ظاهر و رنگ ربات نمایشی

## اجرای پروژه
1. Godot 4.3 یا جدیدتر را نصب کن.
2. از داخل Godot گزینه **Import** را بزن و این پوشه را انتخاب کن.
3. فایل `project.godot` را باز کن و Play را بزن.

## وضعیت APK
این مخزن فعلاً سورس پروژه است. APK فقط پس از اجرای موفق فرایند Export اندروید ساخته می‌شود؛ هنوز فایل APK آماده نیست.
