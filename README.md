# GunFactory

نسخه اولیه بازی مدیریتی اندروید با موتور **Godot 4**.

## ویژگی‌های نمونه اولیه
- رابط کاربری فارسی و مناسب صفحه لمسی
- دریافت سکه با تحویل سفارش‌های خیالی به بات‌ها
- ارتقای سطح کارگاه با سکه‌های بازی
- تغییر طرح و رنگ یک شیء نمایشی انتزاعی
- بدون آموزش یا شبیه‌سازی ساخت، مونتاژ یا استفاده از سلاح واقعی

## اجرای پروژه
1. Godot 4.3 یا جدیدتر را نصب کن.
2. از داخل Godot گزینه **Import** را بزن و این پوشه را انتخاب کن.
3. فایل `project.godot` را باز کن و Play را بزن.

## ساخت APK
برای خروجی اندروید باید Android build template/export setup و Android SDK/JDK در محیط Godot آماده باشند. این مخزن فعلاً سورس پروژه است؛ APK تا زمان اجرای موفق Export ساخته نشده است.
